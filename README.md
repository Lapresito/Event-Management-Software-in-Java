# Event Management Software in Java

Java-based **Event Management System** developed as a university student project.  
The system follows the **MVC architecture** and combines desktop and web technologies, including **Java Swing**, **SOAP Web Services**, and a **Servlet/JSP web layer deployed on Apache Tomcat**.

The project was developed using a **cyclical waterfall approach**, where features were incrementally added over time.  
It was built by **myself and a team of university classmates**, covering both backend and frontend development, with a strong focus on software architecture and separation of concerns.

---

## Technologies & Architecture

- **Java**
- **Java Swing** (desktop client)
- **SOAP Web Services**
- **Apache Tomcat**
- **Java Servlets & JSP**
- **MVC (Model–View–Controller)** architecture

---

## Features

- **User management system** with multiple roles:
  - Users
  - Event organizers
  - Institutions that can sponsor events
- Event creation and management
- Sponsorships and **promoted tickets**
- Authentication and login system
- Web interface designed for **both desktop and mobile**
- Centralized management of events, users, and sponsors

---

## Purpose

This project was created for **academic purposes**, with the goal of applying and reinforcing concepts such as:

- Software architecture and design patterns (MVC)
- Web services integration (SOAP)
- Client–server communication
- Desktop and web application development
- Team-based software development
